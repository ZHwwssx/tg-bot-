# Telegram-бот с правилами

Telegram-бот версии 1.0.0.0 от команды Hareson.

## Что умеет бот

- Отправляет приветственное изображение и подпись.
- Открывает меню «Правила».
- Разделяет правила на «Госс» и «Гетто».
- Показывает правила гетто по категориям: война за территорию, похищение, ВЧ, инкассаторы и угон фур с материалами.
- Делит длинные разделы на страницы, чтобы сообщения не превышали лимит Telegram.
- Добавляет «⬅️ Назад» на каждом внутреннем экране.

Правила раздела «Госс» оставлены как заглушка: в исходном ТЗ их содержание не было указано.

## Запуск

1. Установить зависимости из requirements.txt.
2. Добавить переменную окружения TELEGRAM_BOT_TOKEN с токеном от @BotFather.
3. Запустить: python main.py

Бот использует polling. Flask-сервер на порту PORT (по умолчанию 8080) нужен для health-check при размещении на Render или аналогичном хостинге.

## Структура

- main.py — логика бота, меню и правила.
- welcome.jpg — приветственное изображение.
- requirements.txt — зависимости Python.

## Упоминание участников через @all

- В личном чате команда /start показывает кнопку «Добавить в группу» и инструкции.
- В группе сообщение с @all отвечает кликабельными упоминаниями участников, которых бот уже видел в сообщениях или событиях вступления. Если у человека нет username, он упоминается по имени.
- Telegram Bot API не позволяет получить полный список текущих участников. Люди, которые не писали в группе и не вступали после добавления бота, не попадут в список.
- Чтобы бот видел обычные сообщения, отключите Privacy Mode через @BotFather: /setprivacy → Disable, затем удалите бота из группы и добавьте снова. Вместо этого боту можно выдать права администратора.
- Список хранится в group_members.json. Для сохранения между перезапусками укажите ALL_MENTIONS_STORE на постоянном диске; этот файл исключён из Git.
