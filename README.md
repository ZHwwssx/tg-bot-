# Telegram bot\n\nБот для подготовки к обзвону и подачи анкет.\n\n## Переменные окружения\n\n- `BOT_TOKEN` — токен Telegram-бота.\n- `APPLICATION_GROUP_ID` — ID отдельной Telegram-группы, куда отправляются анкеты (обычно отрицательное число).\n- `LEADER_ID` — Telegram ID лидера.\n- `DEPUTY_ID` — Telegram ID заместителя.\n- `APPLICATION_REVIEWER_IDS` — необязательный список дополнительных ID через запятую.\n- `PORT` — порт веб-сервера.\n\nЕсли `LEADER_ID` и `DEPUTY_ID` не указаны, отвечать на анкеты смогут администраторы группы.\n\n## Сценарий анкеты\n\nПользователь нажимает «Подать анкету», отвечает на вопросы, после чего анкета отправляется в группу. Лидер или заместитель нажимает «Ответить», пишет сообщение, и бот пересылает ответ пользователю.\n
