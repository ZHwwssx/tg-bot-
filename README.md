# Telegram-бот анкеты клана SK

Бот принимает анкету кандидата по шагам, отправляет её в отдельную группу и позволяет лидеру или заместителю ответить кандидату.

## Переменные окружения Render

- BOT_TOKEN — токен Telegram-бота от @BotFather.
- APPLICATION_GROUP_ID — ID группы, куда отправляются анкеты.
- LEADER_ID — необязательный Telegram ID лидера. Нужен для подписи «Сообщение от Лидера клана SK».
- DEPUTY_ID — необязательный Telegram ID заместителя. Нужен для подписи «Сообщение от заместителя клана SK».
- PORT — порт Render.

Если LEADER_ID и DEPUTY_ID не указаны, отвечать смогут администраторы группы, но подпись будет общей: «Сообщение от Лидера или заместителя клана SK».

## Сценарий

1. Пользователь нажимает «Заполнить анкету».
2. Бот по очереди спрашивает NickName, LvL, имя, возраст, Discord, донат, ежедневный онлайн и стаж игры.
3. Последним бот просит отправить голосовое сообщение.
4. После заполнения бот показывает сообщение: «На этом все. Анкета передана Лидеру и Заместителю клана SK.»
5. В группу отправляется сообщение «Анкета», ответы и голосовое сообщение кандидата.
6. Лидер или заместитель нажимает «Ответить» и пишет ответ одним сообщением.
7. Кандидат получает ответ с подписью отправителя и кнопкой «⬅️ Назад».

## Внешний сигнал и Render
