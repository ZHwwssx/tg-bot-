# Telegram-бот с правилами\n\nTelegram-бот версии 1.0.0.0 от команды Hareson.\n\n## Что умеет бот\n\n- Отправляет приветственное изображение и подпись.\n- Открывает меню «Правила».\n- Разделяет правила на «Госс» и «Гетто».\n- Показывает правила гетто по категориям: война за территорию, похищение, ВЧ, инкассаторы и угон фур с материалами.\n- Делит длинные разделы на страницы, чтобы сообщения не превышали лимит Telegram.\n- Добавляет «⬅️ Назад» на каждом внутреннем экране.\n\nПравила раздела «Госс» оставлены как заглушка: в исходном ТЗ их содержание не было указано.\n\n## Запуск\n\n1. Установить зависимости из requirements.txt.\n2. Добавить переменную окружения TELEGRAM_BOT_TOKEN с токеном от @BotFather.\n3. Запустить: python main.py\n\nБот использует polling. Flask-сервер на порту PORT (по умолчанию 8080) нужен для health-check при размещении на Render или аналогичном хостинге.\n\n## Структура\n\n- main.py — логика бота, меню и правила.\n- welcome.jpg — приветственное изображение.\n- requirements.txt — зависимости Python.
