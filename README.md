# Telegram @all bot

Чистый Telegram-бот для упоминания участников группы по команде @all.

## Как использовать

1. Добавьте TELEGRAM_BOT_TOKEN в Secrets / Environment Variables Render. Не храните токен в Git.
2. Напишите боту /start и нажмите «Добавить в группу».
3. Чтобы бот видел обычные сообщения, отключите Privacy Mode у @BotFather командой /setprivacy → Disable и добавьте бота в группу заново. Либо выдайте боту права администратора.
4. Напишите @all в группе. Бот ответит кликабельными упоминаниями участников, которых он уже видел.

## Ограничение Telegram

Bot API не позволяет получить полный список участников группы. Бот запоминает людей, которые написали в группе или вступили после добавления бота. Участники, которые никогда не проявлялись в доступных боту сообщениях, не попадут в список. Пользователи без username упоминаются по имени. При выходе участника бот удаляет его из кэша, если получил соответствующее сервисное сообщение.

## Кэш участников

Новый бот начинает с пустого кэша в /tmp/all_bot_members.json. Для хранения между перезапусками укажите ALL_MENTIONS_CACHE_FILE на постоянный диск в Render. Файл хранит Telegram ID, имя и username участников; локальный файл кэша исключён из Git.

## Запуск и Render

Установите зависимости из requirements.txt и запустите python main.py. Бот использует TELEGRAM_BOT_TOKEN (также поддерживаются TELEGRAM_TOKEN и BOT_TOKEN). Если задан TELEGRAM_WEBHOOK_URL или RENDER_EXTERNAL_URL, включается webhook на /telegram-webhook; иначе бот запускается в режиме polling. Flask health-check доступен по корневому пути, порт берётся из PORT (по умолчанию 8080).
